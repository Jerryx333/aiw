# Agent 运行表兼容（任务 764，未上线）

沿用现有座位输入，增加工具模板和权限上限。旧配置没有新字段时行为不变。

声明 `agent-runtime-v1` 的本地表是完整运行配置，不合入公共座位或备用名单。读取前以稳定 JSON（键排序、UTF-8、紧凑分隔）计算除 version 外全部内容的 SHA-256，与 version 不符就拒绝；运行行必须完整展开，不含 template/base，避免模板变化影响已校验内容。旧配置继续原来的合并规则及安装模板读取。

- `tools.json` 保存版本为 1 的工具模板。座位 `template` 引用工具定义，再合入该行的账号和模型参数；未知模板明确失败，不退回默认工具。
- `force_mode` 只允许 rw、ro、text，执行取用途、命令开关和行上限中最严格的模式。原 `ro_only` 保留；旧名字不会因显式备用链而失去上限。
- 把关和起草不要求另外复制一份只读座位，但必须有明确的只读执行方式。运行前仍核对真实参数；模板存在不代表任意命令安全。
- 模板能力声明与运行表版本检查由消费方确认；新字段未支持前不让 pal 启动真迁移。转发前后均不能放宽模式。

验收：离线模板展开、未知模板拒绝、旧表等价、角色只读、显式链保留只读、备用权限、文本模式；用假工具，不碰真实账号。

已补复验：每个备用按实际模式传附件和记账；转发前剔除本机只读的写候选；doctor 同样展开模板；未指定强度的生成行不传空参数。模板展开优先级为模板、公开行、本地行；当前模板不含权限上限，行上 force_mode 与 ro_only 在执行时取严。

`aiw capabilities` 不加载用户配置，不访问账号，只返回安装版本支持的协议。pal 在首次迁移或启用生成表前实际调用此入口，缺少 agent-runtime-v1 就拒绝切换。

跨机 Agent 转发使用 `agent-desc-v1`：只发送链上条目的规范化配方摘要，不发送命令或凭据。远端用同一安装的配置加载器核对模型、强度、账号引用与配方，保留远端原名执行以沿用停用、熔断和并发状态。只读由请求模式和远端上限取严；可写请求不能匹配只读行。匹配必须唯一，原名完全匹配优先。已知 HOME 路径仅在路径字段规范化。客户端、执行器、aiw 三方能力不齐或不等价则明确拒绝，不将请求改成其他账号。开工时校验有效配置哈希，期间变化则失败而不执行。链上任何 local_only 不转发，skip 不截断本条链的停用成员。

描述包含顶层请求模式，远端每项的有效模式必须不弱于源端该项；停用行参与身份匹配，原名停用不能改借别名。链上 local_only 保留本机执行。远端失败不要求成功身份行，仍取回输出并保留真实失败码。
